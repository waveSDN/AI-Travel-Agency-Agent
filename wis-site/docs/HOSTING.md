# استضافة موقع WIS وربط الدومين

هذه خطة تشغيل للنسخة الحالية، وليست إعلانًا بأن الموقع نُشر. الموقع المحلي على جهاز المؤسس لا يصبح عامًا بمجرد إضافة دومين. لم تُنشأ استضافة ولم يُشترَ دومين.

## خيار البداية: Render Web Service

الخادم مكتوب بـ Node.js وExpress؛ اختر Web Service لخدمة الموقع وواجهة Gemini معًا. اختر خطة مدفوعة لتجنب سكون الخطة المجانية بعد 15 دقيقة دون زيارات. التشغيل المستمر لا يعني ضمان عدم حدوث انقطاع.

إعدادات الخدمة:
- Repository: waveSDN/AI-Travel-Agency-Agent
- Branch للاختبار: claude/inspiring-fermat-tnlwk5
- Root Directory: wis-site
- Runtime: Node.js، إصدار 22
- Build Command: npm ci --include=dev && npm run build
- Start Command: npm start
- للخدمة التجريبية: عطّل النشر الآلي حتى تُراجع التغييرات قبل كل نشر.

متغيرات البيئة في لوحة الاستضافة:
- NODE_ENV=production
- HOST=0.0.0.0
- اترك PORT الذي تحدده الاستضافة.
- ALLOWED_ORIGINS=الرابط الكامل الفعلي للخدمة، بلا شرطة أخيرة، مثل https://اسم-الخدمة.onrender.com. أضف الدومين المعتمد بعد ربطه، وافصل الأسماء بفواصل.
- TRUST_PROXY: اضبطه وفق عدد الوسطاء الموثوقين الفعلي؛ لا تضبطه على true لمجرد تجربة حل.
- GEMINI_ENABLED=false في أول نشر لتجربة الصفحة وروابط التواصل، ثم فعّله بعد إضافة المفتاح وفحص طلب حي محدود.
- GEMINI_API_KEY: أضفه كسر في لوحة الاستضافة. لا تضع قيمته في GitHub أو ملفات الواجهة أو المحادثات.
- GEMINI_MODEL=gemini-3.5-flash-lite
- ASSISTANT_DAILY_LIMIT=100 حد للعملية الواحدة؛ لا تعتمد عليه كسقف مالي دائم أو مشترك.

نقطة البداية المالية بتاريخ 10 أكتوبر 2026: خدمة 512MB مدفوعة بنحو 7 دولارات شهريًا وفق سعر Render. الدومين واستخدام Gemini وأي تجاوزات موارد تكاليف منفصلة. راجع السعر والخطة في لوحة الخدمة قبل الشراء.

## الدومين

- wave.sudan.com اسم فرعي تحت sudan.com؛ يحتاج صلاحية إدارة ذلك الدومين.
- .sa امتداد سعودي، والتسجيل يحتاج استيفاء شروط SaudiNIC والاسم المختار.
- .ksa ليس امتدادًا مسجلًا حاليًا؛ يمكن استعمال ksa ضمن الاسم مثل waveksa.com، دون افتراض توفر هذا المثال.
- امتداد السودان اللاتيني .sd، والعربي .سودان. .sudan بالإنجليزية غير موجود في قاعدة جذور IANA الحالية.
- اقتراحات للنقاش، وليست أسماء متاحة مؤكدة: wavewis.com أو wavewis.sa أو wavewis.sd.

بعد اختيار اسم وامتلاكه: أضفه في Custom Domains، وانقل سجلات DNS المطلوبة من لوحة Render إلى مزوّد الدومين، ثم تحقّق من الربط وشهادة HTTPS. لا تخمّن قيم سجلات DNS قبل إنشاء الخدمة.

## الاختبار قبل تحويله إلى واجهة الشركة

افتح النسخة العامة من شبكة خارجية ومن هاتف. اختبر رابط WhatsApp إلى +966579204081، وملخصًا معدّلًا بالعربية، وعودة المساعد للإجابات المعتمدة عند التعطل. لا تختبر ببيانات عملاء حقيقية.

شغّل npm run check ثم node --test tests/contact-smoke.cjs في نسخة كاملة من المشروع. تُراجع سياسة الخصوصية وحدود Gemini ومحتوى الشركة قبل الإطلاق. أزل noindex ومنع robots.txt عند اعتماد النشر العام. يجب ضبط الوسطاء وحدود الاستخدام، ومراقبة الأعطال، وحفظ التغييرات في GitHub. إذا توسعت الخدمة إلى عدة نسخ، استخدم مخزنًا مشتركًا للحدود والجلسات بحسب التصميم.
